# Swarm Aggregation Project

A swarm robotics simulation in which robots aggregate into a red target region using target attraction, local neighbor communication, spacing, obstacle avoidance, and boundary avoidance.

## Controls

Use the robot window buttons to switch between Easy, Medium, and Hard. Keyboard fallback: `1` for Easy, `2` for Medium, and `3` for Hard.

## Metrics

Metrics are generated in the `swarm_aggregation_project/metrics` folder after aggregation is confirmed. They include aggregation time, percentage in the target region, average distance to target, collision count, and path lengths.
