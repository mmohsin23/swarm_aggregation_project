Swarm Aggregation with Local Communication Instructions:

Use the robot window buttons to switch Easy, Medium, and Hard. The same world is reloaded with the selected scenario. Keyboard fallback: 1 for Easy, 2 for Medium, 3 for Hard.

Robots aggregate into the red target region using target attraction, local neighbor communication, spacing, obstacle avoidance, and boundary avoidance. Metrics are generated automatically in the metrics folder after every robot stays inside the red target region long enough to confirm aggregation.

Generated metrics include aggregation time, percentage in target region, average distance to target, collision count, and path lengths.
